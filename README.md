# Netflix Machine Learning Project

End-to-end Machine Learning project based on the **Netflix Movies and TV Shows** dataset.

## Objective
- Predict whether a Netflix title is a **Movie or a TV Show**
- Segment Netflix content using **unsupervised learning (K-Means clustering)**

## Dataset
- 8,807 titles
- Numerical, categorical and textual features
- Real-world data quality issues (missing values, mixed formats)

## Methodology
- Exploratory Data Analysis (EDA)
- Data cleaning & feature engineering
- Text processing with TF-IDF
- Supervised learning:
  - Logistic Regression
  - K-Nearest Neighbors
  - Decision Tree
- Model evaluation (Accuracy, F1-score, confusion matrix)
- Hyperparameter tuning (GridSearchCV)
- Unsupervised clustering (K-Means)

## Technologies
Python, Pandas, NumPy, Scikit-learn, Machine Learning, Data Science

## Results
- Very high classification performance (F1-score ≈ 1.00)
- Meaningful clusters highlighting Netflix content categories

## Future Work
- Genre prediction and multi-label classification
- Recommendation system
- Deep Learning approaches
